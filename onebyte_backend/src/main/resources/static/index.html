OneByte Auth + MyPage 테스트

Auth: POST /api/users/register POST /api/users/login POST /api/users/logout
MyPage: GET /api/mypage/info PATCH /api/mypage/update PATCH /api/mypage/password POST /api/mypage/withdraw (임시)
- refreshToken 쿠키는 HttpOnly면 JS에서 안 보이는 게 정상
- 쿠키 저장/전송하려면 fetch에 credentials: "include" 필수
- 마이페이지는 accessToken을 Authorization: Bearer로 보냄
